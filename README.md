# 🌦️ Weather Fetching App

A simple and responsive weather application that fetches real-time weather data using a weather API. Users can search for any city and view current weather details instantly.

## 🚀 Features

- Search weather by city name
- Real-time weather updates
- Displays temperature, humidity, and wind speed
- Shows weather conditions with icons
- Responsive design for all devices
- Easy-to-use interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Weather API

## 📸 Preview

Enter a city name and get live weather information including:
- Temperature
- Humidity
- Wind Speed
- Weather Condition
